# Equipo de agentes — cómo usarlo

1. Abre en Cursor la carpeta `C:\Users\sherr\OneDrive\Documentos\prueba Quipux\prueba`.
2. Lee el entregable de prompts: [`../docs/PROMPTS-Y-EQUIPO.md`](../docs/PROMPTS-Y-EQUIPO.md).
3. Ejecuta un chat por rol (o indica el rol al inicio del mensaje), en este orden:
   - Tech Lead → Backend → QA → Security → Documentador
   - Frontend en paralelo cuando el contrato `/lists` esté estable.
4. Copia cada prompt usado a [`../AI-LOG.md`](../AI-LOG.md).

Las reglas Cursor en `.cursor/rules/` aplican automáticamente al trabajar en este workspace.
